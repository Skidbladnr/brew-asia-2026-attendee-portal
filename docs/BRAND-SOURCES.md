# Brand asset provenance

Public assets retrieved 27 October 2026 from the official [Brew Asia website](https://www.brew-asia.com/) and [conference programme page](https://www.brew-asia.com/conference). These assets are included for this event-specific attendee portal. Public availability is not a grant of broader trademark/image rights; organizer branding approval remains part of acceptance.

- `public/assets/brew-asia-2026.png`: official Brew Asia 2026 / Ho Chi Minh City event mark. [Source](https://static.wixstatic.com/media/8cfdb8_0791a206db1645f3b81bc066c866a923~mv2.png)
- `public/assets/barth-haas.jpg`: BarthHaas hall sponsor logo. [Source](https://static.wixstatic.com/media/08f4bf_2e50516591c14384960937f7010fd19a~mv2.jpg)
- `public/assets/joe-white.png`: Joe White Maltings hall sponsor logo. [Source](https://static.wixstatic.com/media/8cfdb8_8c8ce7fd0f784cc98833c20bdf4bca78~mv2.png)

Hall-logo images are decorative beside the corresponding accessible hall names. The event mark has descriptive alternative text. Body copy uses system fonts. Headings use a locally bundled, medium-weight Barlow Semi Condensed face. No font service is contacted at runtime. The tank favicon and desktop brewing-vessel illustration are original SVG code, not official event logos. Local assets avoid runtime dependencies on the event website or font service.

The footer links to [Asia Brewers Network](https://asiabrewersnetwork.com/), the associated brewing community. It does not create a network account or claim a separate membership integration.

`public/assets/BarlowSemiCondensed-Medium.ttf` comes from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed), under SIL Open Font License 1.1. The full license is bundled as `public/assets/OFL-Barlow.txt`.
